# 그림과 화면 규칙

[README.md](README.md) 의 절대 규칙이 먼저다.

## 페이지

비서 페이지는 **자동차 키**다.

```
┌───────────────────────┐
│  사무실 그림 (액정)     │
├───────────────────────┤
│  [시동]  [할 일 버튼]   │  같은 크기로 나란히
├───────────────────────┤
│  흐름도 1 → 2 → 3      │  처리 파랑, 막힘 빨강, 진행 주황
└───────────────────────┘
```

- [ ] 글을 늘어놓지 않는다. 지금 할 일만 시동 크기 버튼으로.
- [ ] 내용은 눌러서 **흰 화면** 체크리스트로 본다.
- [ ] 흰 바탕, 검정 큰 글씨, 설명 최소.
- [ ] 흐름 안에서 여는 화면은 전부 흰 바탕으로 맞춘다. 위쪽 다른 메뉴 바를 넣지 않는다.
- [ ] 폰은 사무실이 맨 위, 그 아래 시동과 내용.
- [ ] 시동은 1초 길게 누른다.
- [ ] 메뉴 이름은 「AI 물류비서」.

## 건물

건물 측면 단면이다. 위에서 내려다보는 맵으로 바꾸지 않는다.

| 항목 | 값 |
|---|---|
| 캔버스 폭 | 720 |
| 층 높이 | 100 |
| 방 폭 | 336, 한 층에 2개 |
| 인물 키 | 약 52 |
| 방 | 비서 1명 = 방 1개, 비서가 늘면 층이 늘어남 |

- [ ] 하얀 유리방, 장식은 적게.
- [ ] 아직 없는 비서의 방은 만들지 않는다.
- [ ] 좌표는 정수로 그린다 (`r` 함수가 반올림함).
- [ ] 부품은 윤곽선 먼저, 색 나중 (`sprite`).

## 인물

머리가 큰 픽셀 인물이다. 앉거나 돌아다니거나 물건을 나른다.

| 비서 | 머리 | 옷 | 자리 |
|---|---|---|---|
| 대표 | 수염 | 회색 `#3f4656` | 책상 |
| 헤드비서 | 단발 | 파랑 `#4e8ad4` | 책상, 램프 |
| 이지어드민 | 짧은 머리 | 노랑 `#f0b83f` | 책상, 쌓이는 송장 |
| 이벗 | 올림머리 | 초록 `#54b98b` | 서서 일함, 선반과 상자 |

새 비서는 옷 색을 겹치지 않게 고른다.

## 색

| 쓰임 | 색 |
|---|---|
| 윤곽선 | `#2a2430` |
| 방 벽 | `#fbfcfb` |
| 바닥 | `#c9553f` |
| 일하는 띠 | `#34b37e` |
| 문제 | `#d8543f` |
| 출근 표시 | `#3b82f6` |
| 퇴근 표시 | `#e5483b` |
| 흐름도 처리 / 막힘 / 진행 | `#1d6fe8` / `#d92b2b` / `#d98a00` |

- [ ] 빨강은 사람이 봐야 할 때만 쓴다.
- [ ] 색만으로 뜻을 전하지 않는다. 이름표 글자도 함께 바꾼다.

## 표현

- [ ] 진행은 일감이 쌓이는 것과 방 위 띠로 보여 준다.
- [ ] 문제는 방 전체를 붉게 한다.
- [ ] 퇴근은 커튼으로 보여 준다.
- [ ] 이름표는 짧게. 비서 이름 + 지금 상태 한 줄.
- [ ] 안정되면 캐릭터 화면만으로 확인과 처리까지 하는 것이 방향이다.
