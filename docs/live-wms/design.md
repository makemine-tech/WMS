# 그림과 화면 규칙

[README.md](README.md) 의 절대 규칙이 먼저다.

## 페이지

비서 페이지는 **자동차 키**다.

```
┌───────────────────────┐
│  사무실 그림 (액정)     │
├───────────────────────┤
│  [시동]  [할 일 버튼]   │  같은 크기로 나란히
├───────────────────────┤
│  흐름도 1 → 2 → 3      │  처리 파랑, 막힘 빨강, 진행 주황
└───────────────────────┘
```

- [ ] 글을 늘어놓지 않는다. 지금 할 일만 시동 크기 버튼으로.
- [ ] 내용은 눌러서 **흰 화면** 체크리스트로 본다.
- [ ] 흰 바탕, 검정 큰 글씨, 설명 최소.
- [ ] 흐름 안에서 여는 화면은 전부 흰 바탕으로 맞춘다. 위쪽 다른 메뉴 바를 넣지 않는다.
- [ ] 폰은 사무실이 맨 위, 그 아래 시동과 내용.
- [ ] 시동은 1초 길게 누른다.
- [ ] 메뉴 이름은 「AI 물류비서」.

## 건물

건물 측면 단면이다. 위에서 내려다보는 맵으로 바꾸지 않는다.

| 항목 | 값 |
|---|---|
| 캔버스 폭 | 720 |
| 층 높이 | 144 |
| 방 폭 | 336, 한 층에 2개 |
| 인물 키 | 약 44~50 (한 칸 2픽셀) |
| 방 | 비서 1명 = 방 1개, 비서가 늘면 층이 늘어남 |

- [ ] 회색 벽, 창밖 야경, 천장 조명. 대표실 책장·화분, 헤드비서실 서류함·복합기, 이지어드민실 서류함, 이벗실 선반·상자·안전선.
- [ ] 소품은 고정 장식이다. 상태를 뜻하는 움직임은 실제 데이터로만 한다.
- [ ] 건물 아래 컨베이어는 실제로 일하는 비서가 있을 때만 움직인다.
- [ ] 맨 윗줄의 상태 글자는 `rooms` 로만 계산한다.
- [ ] 로그인 말풍선은 로그인이 풀린 방에만 띄우고, 비밀번호는 `****` 모양만 그린다.
- [ ] 아직 없는 비서의 방은 만들지 않는다.
- [ ] 좌표는 정수로 그린다 (`r` 함수가 반올림함).
- [ ] 인물은 그림판(글자 줄)으로 그린다. 가구는 `sprite` 로 윤곽선 먼저, 색 나중.

## 인물

머리가 키의 절반쯤인 2등신 픽셀 인물이다. 굵은 까만 윤곽선, 까만 머리 덩어리, 앞쪽 눈 하나와 얼굴 끝의 먼 쪽 눈, 두꺼운 일자 입, 까만 넓은 신발. 그림체만 참고하고 다른 게임의 그림을 그대로 옮기지 않는다.

| 비서 | 머리 | 옷 | 자리 |
|---|---|---|---|
| 대표 | 위로 솟은 머리 | 회색 양복 `#3f4149` | 책상 |
| 헤드비서 | 긴 머리 | 파랑 `#3f7fd0` | 책상, 램프 |
| 이지어드민 | 짧은 머리 | 노랑 `#f0b83f` | 책상, 쌓이는 송장 |
| 이벗 | 주황 모자 `#e88a2c` | 초록 `#3fa877` | 서서 일함, 선반과 상자 |

새 비서는 옷 색을 겹치지 않게 고른다.

- [ ] 빨강은 사람이 봐야 할 때만 쓴다.

## 표현

- [ ] 진행은 일감이 쌓이는 것과 방 위 띠로 보여 준다.
- [ ] 문제는 방 전체를 붉게 한다.
- [ ] 퇴근은 커튼으로 보여 준다.
- [ ] 이름표는 짧게. 비서 이름 + 지금 상태 한 줄.
- [ ] 안정되면 캐릭터 화면만으로 확인과 처리까지 하는 것이 방향이다.
