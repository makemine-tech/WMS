# 비서별 업무 흐름

[README.md](README.md) 의 절대 규칙이 먼저다. 각 표의 「현재」는 2026-11-02 기준이고, 바뀌면 여기를 고친다.

## 이지어드민 비서: 곡물도감

사람이 정한 범위: **3번 일괄합포제외까지.** 송장출력은 불안정해 뺐고 합포 분할 화면에서 직접 한다.

| 번호 | 칸 | 누가 | 캐릭터 | 현재 |
|---|---|---|---|---|
| 1 | 접속·로그인 | 비서 | 로그인 풀리면 붉은 방 | 동작 |
| 2 | 주문 미리 보기 | 비서 | 책상에서 일함, 송장 쌓임 | 동작 |
| 3 | 일괄합포제외 | 사람이 누르고 상시 컴퓨터가 실행 | 저장 중 서류 들고 움직임 | 동작, 실제 저장 확인 |

### 확인 필요

사람에게 보여 주는 것은 이것뿐이다. 나머지는 작업자가 육안으로 거른다.

- 60박스를 넘는 송장
- 모르는 상품
- 수량 없는 주문

이지어드민 응답의 `fail_list` 는 실패가 아니라 **미분할 목록**이다. 애초에 채우지 않은 주문이 대부분이다. 실제 반영 여부는 다시 검색해 대조한다.

### 지킬 것

- [ ] 비서 안 화면은 합포 분할 화면과 같아야 한다. 다른 점은 도우미가 필요 없다는 것과 흰 바탕뿐이다.
- [ ] 수령자 이름 대신 묶음번호를 보여 준다.
- [ ] 불러오기는 사람이 누를 때만 한다.
- [ ] 채운 뒤 탭이 새로 열렸으면 저장하지 않는다.

### 시간표 (만들 때)

- 월~금 09:00 또는 09:30, 14:20
- 수동 클릭은 항상 가능, 이미 수동으로 한 회차는 건너뜀
- 스케줄을 켤 때 폰 알림도 함께

## 이벗 비서: 맨소래담

사람의 판단은 **주문 매칭과 사은품 확인 둘뿐이다.** 나머지는 비서가 하는 것이 최종 목표다.

| 번호 | 칸 | 누가 | 현재 |
|---|---|---|---|
| 1 | 주문 수집 (이벗 + 비젬 엑셀) | 비서 | 읽기만, 수집은 사람 |
| 2 | 주문 매칭 | **사람** | 화면 있음, 이벗 저장 전 |
| 3 | 묶음 출력확정 | 비서 | 읽기만 |
| 4 | 사은품 | **사람 확인** | 대상 계산, 넣기 미구현 |
| 5 | 송장번호 | 비서 | 읽기만 |
| 6 | 출고처리 | 비서 | 읽기만 |
| 7 | 이벗 송장전송 | 비서 | 미구현 |
| 8 | 비젬 송장전송 | 비서 | 미구현, 비젬 연결 전 |

### 지킬 것

- [ ] 판매처 맨소레담공식스마트스토어만 자동수집 대상이다.
- [ ] 수집이 끝나기 전에 다시 수집하지 않는다. 중복 등록된다.
- [ ] 수집 중에는 매칭하지 않는다.
- [ ] 출력취소하면 송장번호가 지워진다.
- [ ] 주문서삭제 메뉴는 다운로드만 쓴다.
- [ ] 시작 전에 행사 세부를 미리 묻지 않는다. 사람이 알려 준다.

### 사은품

- 대상 브랜드가 든 주문의 **주문 전체** 판매금액 (할인 후, 배송비 제외)
- 주문당 가장 높은 구간 하나
- 연동몰 제외

## 헤드비서

| 일 | 현재 |
|---|---|
| 시동을 받아 비서를 깨움 | 동작 |
| 화면 요청을 사이트 탭으로 전달 | 동작 |
| 출력·저장 중 탭 보호 | 동작 |
| 10분 로그인 점검 | **꺼 둠.** 탭을 새로 열어 출력 중 페이지가 넘어갔다. 탭을 안 건드리는 방식으로 다시 만든다 |

| 비서 화면 로그인 입력 | 만듦, 실제 사이트 시험 전. 보안문자가 있으면 직접 로그인 |

## 업무 사건과 캐릭터 행동

새 업무를 붙일 때 이 표에 한 줄씩 늘린다. 왼쪽이 실제 데이터로 확인되지 않으면 오른쪽을 보여 주지 않는다.

| 실제 사건 | 어디서 아나 | 행동 |
|---|---|---|
| 상시 컴퓨터 신호 끊김 | `secretary/runner.ts` | 전원 커튼 |
| 로그인 풀림 | `secretary/sites/{id}.state` | 그 방 붉어짐 |
| 시동 후 읽는 중 | `jobs` `running` | 그 비서 work |
| 일괄합포제외 저장 중 | `jobs` `ez_split` `running` | 이지어드민 비서 work, 이름표에 단계 |
| 예상 송장 수 | `preview.invoices` | 이지어드민 방에 송장 쌓임 |
| 사은품 넣을 주문 | `menso.campaigns[].need` | 이벗 이름표에 건수 |
| 해야 할 일 수 | 흐름도 빨간 칸 | 대표실 이름표에 건수 |
