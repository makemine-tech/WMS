# 입고검수 → 작업 종료 때 재고 자동 입고 (설계)

## 왜
지금은 입고 시스템(star_coupang.html)에서 검수 → 「📦 재고 입고용 엑셀」 내려받기 → 재고관리(star_instock)에 올리기를 사람이 따로 한다.
시간이 지나면 올렸는지 잊고, 동시입출고까지 섞여 재고가 두 번 잡히거나 빠진다. 작업 종료 한 번에 입고까지 끝내고 싶다.

## 목표
- 「🏁 작업 종료 + 세션 정리」 → 「🏁 작업 종료 + 입고 잡기 + 세션 종료」.
- 누르면 검수 결과를 재고관리 입고 기록으로 바로 올린다 (지금 재고 입고용 엑셀과 같은 내용: 박스 × 품목, 정상 = 재고, 불량 = 불량수량).
- **초과는 잡지 않는다**: 품목마다 정상 입고 = min(실입고, 목표). 목표 = 예정수량 − 기존수량 (화면의 목표와 같음). 넘친 수량은 마지막에 찍은 박스부터 뺀다.
- 미리 보기 창에서 확인 후 반영: 품목 수 · 입고 수량 · 불량 · 특이사항(초과 잘라냄, 예정에 없는 신규 바코드, 동시입출고와 겹침 🔴🟡🟢, 이미 재고관리에 같은 박스 입고 기록 있음).
- 반영 후 세션 정리(지금과 같음). 입고를 건너뛰고 정리만 하는 길도 남긴다 (이미 엑셀로 올린 작업 등).

## 하지 않는 것
- 동시입출고 수량을 자동으로 빼지 않는다. 대표님 작업 방식: 동시입출고 먼저(가상 입고 → 출고), 남은 실물만 스캔. 겹침은 특이사항으로만 보여 준다.
- 입고예정 리스트가 없는 작업(자료 없이 시작)은 스캔한 만큼 그대로 (목표가 없으므로 자르지 않음).

## 지키는 것
- 같은 작업을 두 번 입고하지 않는다: 입고하면 세션에 「입고 완료(시각·건수)」 표시 + 재고관리에 같은 박스바코드 입고 기록이 이미 있으면 경고하고 기본은 막는다.
- 입고 기록 형식은 엑셀 일괄 입고와 같게 (source 'excel', batchId B+시각, batchName = 「입고검수 <작업명>」) → 재고관리 작업별 기록에 한 줄로 보이고 엑셀로 내려받을 수 있다.
- 대체바코드는 입고 자료의 값 그대로 (추측·변형 금지).

## 방식 (고른 것)
- A. 입고 시스템의 작업 종료 버튼에 입고를 붙인다 — **선택**. 대표님이 이미 쓰는 화면·흐름 그대로.
- B. 재고관리에 별도 입고 작업 추가 — 입고 화면이 둘로 나뉘어 헷갈림.
- C. 엑셀 업로드만 보강 — 지금의 「잊어버림」 문제가 그대로.

## 빌더 몫
- 미리 보기 창 모양, 특이사항 문구, 세션 표시 저장 위치.
- 예정에 없는 신규 바코드(isNew): 기본 제외, 미리 보기에서 체크하면 포함.
