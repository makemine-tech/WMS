광고 관제는 네 군데와 연결됩니다

1) 네이버 검색광고 API — 광고 성과·입찰가

네이버 검색광고캠페인·키워드·입찰가·성과
⇄
서버 함수 (구글 서울)30분마다 수집 · 10분마다 예산 지킴이 · 입찰 변경
→
광고 관제 화면위 「마지막 수집」
열쇠 3개가 서버 비밀 저장소에만 있음: NAVER_SA_API_KEY(액세스라이선스) · NAVER_SA_SECRET_KEY(비밀키) · NAVER_SA_CUSTOMER_ID(고객 ID). IP 제한 없음 — 어느 컴퓨터가 꺼져 있어도 상관없음.

2) 네이버 데이터랩 — 시즌 검색 추이

네이버 데이터랩검색어 트렌드
→
서버 함수하루 한 번
→
시즌 검색 추이 그래프
열쇠 2개: NAVER_DATALAB_CLIENT_ID · NAVER_DATALAB_CLIENT_SECRET. IP 제한 없음.

3) 스마트스토어 커머스 API — 매출 (⚠️ 유일하게 컴퓨터가 필요)

네이버 커머스API센터등록한 IP 에서만 응답
→
스토어 수집 컴퓨터고정 IP · 작업 스케줄러 10분마다 · 드롭박스 MAKEWON\스토어수집기
→
서버 받는 창구adsStoreIngest → 화면 「스토어 매출」 줄
커머스 API 는 커머스API센터에 등록한 「API 호출 IP」 에서만 불러집니다. 구글 서버는 IP 가 계속 바뀌어 등록할 수 없어서, IP 가 고정된 사무실 컴퓨터가 대신 받아 서버로 보냅니다. 열쇠: 수집 컴퓨터에는 애플리케이션 ID·시크릿(그 컴퓨터·그 윈도우 사용자만 풀 수 있게 암호화), 서버에는 같은 시크릿 NAVER_COMMERCE_CLIENT_SECRET(받은 자료가 진짜 우리 수집기 것인지 서명 확인용).
IP 가 바뀌는 컴퓨터(수시로 껐다 켜는 컴퓨터, 와이파이 옮겨 다니는 노트북)에는 설치하지 마세요. IP 가 바뀌는 순간 매출 수집이 끊깁니다.

→
푸시 알림
→
픽앤톡에서 알림을 허용한 휴대폰
광고 관제 「⚙ 하루 예산」 → 「🔔 알림 시험」 으로 확인.

증상별 점검 순서

화면에 보이는 것뜻이렇게 확인·해결
맨 위 「수집 실패 … 401 / 403 / 인증」검색광고 API 열쇠가 바뀌었거나 만료
  1. 네이버 검색광고 → 도구 → API 사용 관리에서 액세스라이선스·비밀키가 살아 있는지 확인(새로 발급했다면 아래로)
  2. 서버 비밀값을 새 값으로: firebase functions:secrets:set NAVER_SA_API_KEY (비밀키·고객 ID 도 같은 방식)
  3. 함수를 다시 배포해야 새 값이 적용: firebase deploy --only functions:ads
  4. 광고 관제 「⟳ 지금 새로 받기」 → 「마지막 수집 (지금 시각)」 확인
맨 위 「마지막 수집」 시각이 1시간 넘게 그대로30분 자동 수집이 안 돎
  1. 「⟳ 지금 새로 받기」 를 눌러 오류 문구 확인 → 위 줄처럼 처리
  2. 오류 없이 되면 일시적 — 다음 30분 수집을 지켜봄
  3. 계속이면 Firebase 콘솔 → Functions → adsCollect 로그 확인(결제·할당량 문제일 수 있음)
「스토어 매출」 줄 「40분 넘게 소식 없음」 (빨강)수집 컴퓨터가 안 보냄
  1. 수집 컴퓨터가 켜져 있고 윈도우에 로그인돼 있는지(화면 잠금은 괜찮음, 로그아웃·절전은 안 됨)
  2. 인터넷 연결 확인
  3. 작업 스케줄러 → 「MAKEWON 스토어 매출」 → 상태 「준비」, 마지막 실행 결과 0x0 인지
  4. 수집 컴퓨터에서 로그 열기: %LOCALAPPDATA%\MakewonStore\log.txt (탐색기 주소창에 붙여넣기) → 마지막 줄의 오류를 아래 표에서 찾기
  5. 작업이 없으면 → 「🖥 스토어 수집기 설치·옮기기」 마법사로 다시 설치
「스토어 매출 실패 — 스토어 인증 실패 403 … IP」수집 컴퓨터의 공인 IP 가 바뀜
  1. 수집 컴퓨터에서 네이버에 「내 아이피」 검색 → 지금 IP 확인
  2. 커머스API센터 → 애플리케이션 → API 호출 IP 에 그 IP 추가(예전 IP 는 지워도 됨)
  3. 10분 기다리거나 작업 스케줄러에서 작업 「실행」 → 화면 「마지막 받음」 확인
  4. 자주 바뀌면 통신사에 고정 IP 신청 또는 고정 IP 컴퓨터로 옮기기
「스토어 인증 실패 401」 · 「시크릿 모양이 아닙니다」애플리케이션 시크릿이 틀렸거나 새로 발급됨
  1. 커머스API센터에서 시크릿 확인(새로 발급했다면 예전 것은 못 씀)
  2. 수집 컴퓨터: 드롭박스 스토어수집기\설치.cmd 다시 실행 → 새 ID·시크릿 넣기 (덮어씀)
  3. 서버도 같은 시크릿으로: firebase functions:secrets:set NAVER_COMMERCE_CLIENT_SECRET → firebase deploy --only functions:ads
로그에 「받는 창구 401 bad sign」수집기 시크릿 ≠ 서버 시크릿 위 줄 3번처럼 서버 비밀값을 수집기와 같은 시크릿으로 맞추고 함수 다시 배포
로그에 「받는 창구 400」수집 컴퓨터 시계가 10분 넘게 틀림 윈도우 설정 → 시간 및 언어 → 날짜 및 시간 → 「지금 동기화」
「스토어 매출」 이 「실패」 와 「받음」 사이를 오락가락예전 수집 컴퓨터가 아직 돌고 있음 예전 컴퓨터에서 드롭박스 스토어수집기\제거.cmd 실행 → y
수집 컴퓨터 화면에 10분마다 창이 깜빡 뜸예전 방식으로 등록된 작업 그 컴퓨터에서 스토어수집기\창숨김_적용.cmd 한 번 실행 (키 다시 안 넣어도 됨)
시즌 검색 추이 그래프가 비거나 「데이터랩 … 」 오류데이터랩 열쇠 문제 데이터랩 애플리케이션의 Client ID·Secret 확인 → firebase functions:secrets:set NAVER_DATALAB_CLIENT_ID / …_SECRET → 함수 다시 배포 → 그래프 옆 「⟳」
예산 알림이 휴대폰에 안 옴알림 받을 기기가 없음 그 휴대폰에서 픽앤톡 열기 → 알림 허용 → 광고 관제 「⚙ 하루 예산 → 🔔 알림 시험」 에서 「기기 n대」 확인
광고가 전부 멈춤 · 「비즈머니가 모자랄 수 있어요」비즈머니 잔액 부족 네이버 검색광고에서 비즈머니 충전. 예산 소진으로 꺼진 캠페인은 다음 날 정한 시각에 자동으로 다시 켜짐
