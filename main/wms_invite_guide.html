카톡 안에서는 Google 로그인이 막혀 있어요. 아래 버튼으로 휴대폰 기본 브라우저(크롬·사파리)에서 열어 주세요.
🌐 휴대폰 브라우저로 열기
1

휴대폰 브라우저에서 열기

카톡으로 받은 링크를 누르면 카톡 안의 화면으로 열립니다. 여기서는 Google 로그인이 되지 않으니 크롬 또는 사파리로 열어 주세요.

  • 안드로이드 : 오른쪽 위 ⋮ → 다른 브라우저로 열기
  • 아이폰 : 오른쪽 아래 ··· (또는 공유 버튼) → Safari로 열기
PC에서 하셔도 됩니다. 크롬에서 아래 로그인 주소를 열어 주세요.
2

Google 계정으로 로그인

아래 버튼으로 로그인 화면을 열고 「Google 계정으로 로그인」을 눌러 주세요. Google(Gmail) 계정이 필요합니다.

창고관리 화면이 열리면 끝!

안 될 때

「유효하지 않은 / 만료된 / 이미 사용된 초대 코드」라고 나와요

초대코드는 24시간 안에 한 번만 쓸 수 있습니다. 메이크창고 담당자에게 새 코드를 요청해 주세요.

Google 로그인 버튼을 눌러도 넘어가지 않아요

카톡 안의 화면에서 열렸을 가능성이 큽니다. 1번처럼 크롬·사파리로 열기를 한 뒤 다시 해 주세요.

코드를 넣었는데 다음에 들어가니 다시 코드를 물어봐요

처음과 다른 Google 계정으로 로그인하셨을 수 있어요. 창고 화면 오른쪽 위 ⋮ → 로그아웃 (코드 입력 화면이면 맨 아래 「로그아웃」) 후 처음 계정으로 다시 로그인해 주세요.

창고가 보이지 않거나 「권한이 없어요」라고 나와요
